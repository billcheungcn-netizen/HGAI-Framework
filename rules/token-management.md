# Token 与检索成本管理规则

## 定位阶梯

从上到下成本和误判风险逐级增加：

```text
1. 指定文件或接口
2. 指定模块或目录
3. 根据终端用户现象查模块地图
4. 在受限范围内搜索
5. 全仓搜索
```

AI 必须从能够解决任务的最精确层开始。只有真实证据表明当前范围不足时，才能扩大一级。

## 扩大范围时必须记录

- 已经读取了哪些文档、规则、模块和文件；
- 当前证据为什么不足；
- 下一层检索范围；
- 预计要回答的具体问题；
- 是否因为模块地图、术语表或索引过期导致额外检索。

## 禁止

- 不得为了“先了解一下”默认读取整个仓库；
- 不得反复读取已经在权威文档中确认的相同事实；
- 不得把所有历史任务长期塞进 `AGENTS.md`；
- 不得用超长提示重复常驻规则；
- 不得为了省输出 Token 而省略必要验证，Token 优化不能牺牲正确性。

## 任务结束时

如果定位成本过高，应更新模块地图、术语表、规则或索引；如果结构本身导致无法精确定位，应建立重构任务。
