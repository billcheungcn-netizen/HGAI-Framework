# Claude Code 项目入口

开始任何任务前：

1. 完整阅读项目根目录的 `AGENTS.md`；
2. 阅读 `docs/rules/INDEX.md` 及当前任务适用的规则；
3. 根据 `docs/system/MODULE_MAP.md` 定位责任模块；
4. 根据任务风险选择 `TASK_LITE.md`、`TASK.md` 或 `BUG.md`；
5. 技术过程写入内部文档，面向项目负责人的反馈遵守 `docs/rules/user-facing-communication.md`；
6. 不得绕过 Git、测试、文档防腐、依赖与密钥治理规则。

如果本文件与权威规则冲突，以 `docs/rules/` 和项目 `AGENTS.md` 为准。
