# AI 开发每日执行清单

## 开始任务前

- [ ] AI 已完整阅读 `AGENTS.md`
- [ ] 已查找相关历史需求、Bug、决策和重构文档
- [ ] 已通过模块地图定位责任模块
- [ ] 已确认目标目录、文件和主要调用入口
- [ ] 已明确哪些模块和文件不能修改

## 写代码前

- [ ] 已建立任务或 Bug 文档
- [ ] 已保留原始需求原话
- [ ] AI 已书面复述需求
- [ ] 已列出文件级执行计划
- [ ] 已检查单向依赖、高内聚低耦合和业务边界
- [ ] 已写明禁止采用的兜底、兼容、重复实现和跨模块方案
- [ ] 已写明验收标准
- [ ] 高风险任务已经人工确认计划

## 执行过程中

- [ ] 修改范围没有擅自扩大
- [ ] 实际代码与计划一致
- [ ] 没有顺手修改无关代码
- [ ] 没有创建第二套平行实现
- [ ] 没有用默认值、吞错或兜底隐藏根因
- [ ] 遇到结构不一致时已暂停并更新计划
- [ ] 重要判断已记录进任务文档

## 完成验证

- [ ] 真实用户流程符合验收标准
- [ ] Bug 已完成修复前后对照
- [ ] 构建、测试、类型检查和静态检查已实际执行
- [ ] 没有新增反向依赖、循环依赖或跨层调用
- [ ] 没有遗留临时兼容和旧实现
- [ ] 任务文档与最终代码一致

## 结束任务

- [ ] 已记录实际修改文件
- [ ] 已记录验证命令和真实结果
- [ ] 已记录与原计划的差异
- [ ] 已更新模块地图、架构文档或术语表
- [ ] 已更新 `AGENTS.md` 索引
- [ ] 未完成内容已写入 handoff
- [ ] 已判断是否需要建立重构任务

## 出现以下情况立即暂停增加功能

- [ ] AI 多次找错模块
- [ ] 一个小任务需要扫描大量无关代码
- [ ] 同一职责出现多个实现
- [ ] 兜底或兼容分支持续增加
- [ ] 模块依赖开始反向或循环
- [ ] 文件职责无法清楚解释
- [ ] 文档、索引和代码现实不一致

任何一项被勾选，都应先进行架构审计或重构，再继续堆功能。
